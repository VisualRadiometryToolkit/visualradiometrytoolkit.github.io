# AGENTS.md

Instructions for coding agents in this repository live in **[CLAUDE.md](CLAUDE.md)**
(workspace-wide) and in each package's own `CLAUDE.md`. Read both before
working in a package. The stack conventions are the Visual Geometry Toolkit's:
the files of
[VisualGeometryToolkitCore/conventions/](https://github.com/VisualGeometryToolkit/VisualGeometryToolkit.jl/tree/main/VisualGeometryToolkitCore/conventions),
in the order its README gives. They ship with the installed package
(`VisualGeometryToolkitCore.conventions_dir()`); read them there.

Where CLAUDE.md names Claude in the commit rules, read it as any agent: never add
an AI co-author line or a "generated with" footer to a commit message.

The **privacy boundary** in CLAUDE.md binds every agent: this repository is
public, and nothing unpublished enters it.
