VisualRadiometryToolkitCore — Module
VisualRadiometryToolkitCore

The core of the Visual Radiometry Toolkit: the types of a radiometric camera, a camera of the Visual Geometry Toolkit (VisualGeometryToolkitCore) together with the parts that decide how much light a pixel collects. Radiometry lifts geometry: this package depends on VisualGeometryToolkitCore and follows its conventions; nothing there depends on this.

Under construction (version 0.0.1, not registered). It holds the first part born here, NoVignetting; the rest of the layout is planned in the comments of this file and in the manual's Design page.

Vignetting

VisualRadiometryToolkitCore.NoVignetting — Type
NoVignetting()

The absent vignetting: V ≡ 1 everywhere on the sensor. It has no parameters, so it adds no coordinates to a calibration and no columns to a Jacobian, and it is the default vignetting of a radiometric camera: a camera that is not given one attenuates nothing.

It is a singleton that compiles away. Called at a sensor point, v(u) (and v(u, f) with the point's ray), it returns true, the multiplicative identity of every number type: true * x === x for a float, a dual number or a quantity, so a kernel that multiplies by the value is compiled to one that does not multiply. A kernel can also take a method for ::NoVignetting and skip the factor altogether.

The parameter protocol of VisualGeometryToolkitCore answers for it with nothing: parameter_vector is empty, parameter_names is (), and with_parameters takes the empty vector and returns it unchanged.

Examples

julia> using StaticArrays: SVector

julia> v = NoVignetting();

julia> v(SVector(1200.0, 800.0))
true

julia> v(SVector(1200.0, 800.0)) * 0.25
0.25

julia> length(parameter_vector(v))
0
